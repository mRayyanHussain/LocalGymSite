# Muscle Factory - LocalGymSite

Welcome to the **Muscle Factory** website project — a responsive, multipurpose landing page for a local gym.

---

## Project Overview

This is a simple yet elegant website designed to showcase gym features, gallery, schedules, trainers, and contact information for a fitness center called *Muscle Factory*.

The website is built using:

- HTML5
- CSS3 (Bootstrap framework)
- JavaScript (jQuery and plugins)
- Google Fonts (Roboto)
- Responsive design principles for mobile friendliness

---

## Features

- **Responsive Navbar** with smooth scrolling navigation  
- **Image Gallery** showcasing gym facilities  
- **Features Section** highlighting gym promises and services  
- **Trainer Info and Contact Details**  
- Clean and modern design with animations using `animate.css` and `wow.js`  
- Bootstrap grid layout for flexible page structure
